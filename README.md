# Blogs API

API REST de blog com autenticação JWT, usuários, categorias e postagens persistidas em MySQL.

## Funcionalidades e aprendizados

- API REST de blog com autenticação JWT
- Código organizado para estudo e evolução
- Prática das tecnologias utilizadas no repositório

## Tecnologias

- JavaScript
- Node.js
- Express
- Sequelize
- MySQL
- Jest

## Como executar

```bash
git clone https://github.com/rita-moura/25-Project-Trybe-Blogs-Api.git
cd 25-Project-Trybe-Blogs-Api
npm install
npm run dev
```

### Comandos úteis

- `npm test`: executa os testes.
- `npm run lint`: verifica a qualidade do código.
